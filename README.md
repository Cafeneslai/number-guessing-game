# เกมส์ทายตัวเลข (Number Guessing Game)

# ผู้จัดทำ
- นายชุติพนธ์ จิตต์รุ่งเรืองสุข 67160003
- นายพัชรพงษ์ สังข์กล่อม 67160193

# มหาวิทยาลัย
- มหาวิทยาลัยบูรพา ITDI 67

## ความเป็นมา
โปรแกรมเกมส์ทายตัวเลข 1-100 เขียนด้วย HTML, CSS และ Vanilla JavaScript

## เวอร์ชัน
- v1: เวอร์ชันพื้นฐาน
- v2: เพิ่ม Bootstrap, validation, counter
- v3: เพิ่มตัวจับเวลา 60 วินาที พร้อมเอฟเฟกต์ความกดดัน

## วิธีการใช้
1. เปิด `index.html` ในเบราว์เซอร์
2. พิมพ์ตัวเลข แล้วคลิก "ทาย"
3. โปรแกรมจะบอกว่าสูงไป/ตํ่าไป/ถูกต้อง
4. ทายตัวเลขให้ถูกก่อนหมดเวลา 60 วินาที!

## ข้อกําหนด
- HTML5
- CSS3 (Bootstrap 5)
- JavaScript ES6+

## ✨ ฟีเจอร์ใหม่ (v3)

### ⏱️ ตัวจับเวลา 60 วินาที
- แสดงผลแบบวงกลมพร้อม progress bar
- หยุดอัตโนมัติเมื่อทายถูกหรือหมดเวลา
- แสดงเวลาที่เหลือเมื่อทายถูก

### 🎨 เอฟเฟกต์ความกดดัน 3 ระดับ

| เวลาเหลือ | สถานะ | เอฟเฟกต์ |
|-----------|-------|----------|
| 21-30 วินาที | 🟠 Urgent | สีส้ม + กล่องเรืองแสง + beep ทุก 5 วิ |
| 11-20 วินาที | 🟡 Warning | สีเหลือง + pulse effect + beep ทุก 2 วิ |
| ≤10 วินาที | 🔴 Critical | สีแดง + สั่น + กระพริบ + beep ทุกวินาที |

### 🔊 เสียง Beep
- สร้างด้วย Web Audio API (ไม่ต้องโหลดไฟล์)
- ความถี่สูงขึ้นเมื่อเวลาเหลือน้อย
- เสียงเบาไม่รบกวน

### 🎮 การเล่น
- กดปุ่ม "ทาย" หรือกด Enter เพื่อทาย
- กดปุ่ม "เริ่มใหม่" เพื่อรีเซ็ตเกมและเวลา
- เมื่อหมดเวลาจะแสดงคำตอบที่ถูกต้อง
